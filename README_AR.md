# رفيق الصلاة — مشروع أندرويد أولي

مشروع Kotlin + Jetpack Compose + Room، بواجهة عربية RTL، وبدون صلاحية إنترنت أو إشعارات. تحفظ تغييرات اليوم محليًا في قاعدة بيانات SQLite/Room.

## ما تم بناؤه في هذه النسخة
- نموذج قاعدة بيانات يومية مستقل لكل تاريخ، مع جداول منفصلة للفروض والسنن الرواتب والإعدادات.
- منطق مستقل لتقييم الفروض: جماعة، منفردًا، قضاء، وتسجيل غير مكتمل.
- النقاط لا تظهر في الواجهة؛ الظاهر نسبة الإنجاز من 100% وتقدير الفروض.
- تسجيل الفروض، قيام الليل، الوتر، الضحى، قبل العصر، النوافل، السنن الرواتب، صفحات القرآن والأذكار كحالات.
- حفظ تلقائي محلي عبر Room.
- اختبارات وحدة أساسية لمنطق التقييم والنسبة.

## تنبيه عن اكتمال المنتج
هذه نسخة تأسيسية وليست بعد التطبيق النهائي بكل المواصفات. ما زال يلزم تنفيذ: تصدير/استيراد النسخة الاحتياطية، نصوص الأذكار، إضافة/حذف الأهداف الشخصية، صفحة سجل الأيام والإحصائيات، إعدادات الأهداف بواجهة مستخدم، وملخص يومي كامل. كما أن تسجيل الأجزاء والسور محفوظ جزئيًا في النموذج لكنه لا يملك واجهة إدخال مكتملة في هذه النسخة.

## بناء APK
يتطلب البناء Android SDK وGradle (أو Gradle Wrapper) واتصالًا أوليًا لتنزيل اعتماديات Gradle. من مجلد المشروع بعد فتحه في Android Studio:
1. افتح مجلد `rafiq_salah` كمشروع.
2. ثبّت Android SDK Platform 35 وJDK 17.
3. نفّذ Sync Project with Gradle Files.
4. شغّل اختبارات `testDebugUnitTest`.
5. من Build اختر Build APK(s)، أو نفّذ `gradle assembleDebug` من الطرفية.
6. ملف APK المتوقع: `app/build/outputs/apk/debug/app-debug.apk`.

لم يتم تضمين APK في هذه الحزمة لأن بيئة الإنشاء الحالية لا تحتوي على Android SDK أو Gradle، وبالتالي لم يمكن بناء التطبيق أو اختباره على جهاز فعلي هنا. لا تعتبر هذه النسخة APK جاهزًا للتثبيت.
